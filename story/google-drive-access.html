Sharing Files in Google Drive

See how to share a file from Google Drive, set it to Viewer, Commenter or Editor, and notify the people you invite.

By StoryCast Studio

Full transcript

  1. On screen

    Google Drive home page (drive.google.com). Suggested files are shown, and one file is selected with the toolbar visible above the list.

  2. On screen

    Suggested folders now appear above the suggested files.

  3. On screen

    A document is selected from the list of suggested files.

  4. On screen

    The Share dialog opens for the document. Under “General access”, “Anyone with the link” is set to Viewer, and a Copy link button is shown.

  5. On screen

    The role drop-down is open, offering Viewer, Commenter and Editor.

  6. On screen

    The role is changed to Editor, and a small message confirms “Access updated”.

  7. On screen

    A person has been added in the people field with the Editor role. A “Notify people” box is ticked and a message box sits below, with Cancel and Send buttons.

  8. On screen

    The cursor is placed in the message box, ready to type.
